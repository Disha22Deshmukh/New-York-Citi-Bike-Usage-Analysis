The NYC Citi Bike Sharing Data Analysis project focuses on analyzing bicycle-sharing trips in New York City, USA. The main objective is to understand bike-sharing usage patterns, customer behavior, trip duration, trip distance, popular starting stations, and the influence of weather conditions on bicycle usage.

The project uses Python libraries such as Pandas and NumPy for data processing and Matplotlib and Seaborn for data visualization.

The analysis explores different aspects of bike-sharing services, including hourly and daily ride patterns, differences between registered members and casual users, weekday and weekend usage, and the relationship between trip duration, distance, and weather conditions.

The project also includes a data collection notebook that retrieves historical weather information from the Open-Meteo API and Citi Bike station information from the Citi Bike GBFS API.

The overall goal is to extract meaningful insights from the dataset and understand how people use bicycle-sharing services in New York City.# New-York-Citi-Bike-Usage-Analysis
